# UML Change Checklist

Update the corresponding diagrams when the answer is yes:

- [ ] External actor or system boundary changed → system context/use cases.
- [ ] Deployable unit or storage dependency changed → container/deployment.
- [ ] Component responsibility, port, or dependency changed → component diagram.
- [ ] Domain type, relationship, or invariant changed → domain model.
- [ ] Schema compilation stages changed → compilation sequence.
- [ ] Runtime access behavior changed → interpretation sequence.
- [ ] CLI/daemon branch or job flow changed → activity diagram.
- [ ] Schema/artifact lifecycle changed → state machine.
- [ ] Generator/build stages changed → code-generation diagram.
- [ ] Plugin or extension contract changed → extension-points diagram.
